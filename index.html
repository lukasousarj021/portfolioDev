👋 Olá, eu sou Lukas

Desenvolvedor Front-End apaixonado por criar interfaces modernas, responsivas e intuitivas utilizando tecnologias nativas da Web.

HTML5 CSS3 JavaScript Responsive Dark Mode i18n

📖 Sobre o Projeto

Este portfólio foi desenvolvido com foco em performance, acessibilidade, organização do código e uma ótima experiência para o usuário.

Todo o projeto foi construído utilizando HTML, CSS e JavaScript puro, sem frameworks, visando demonstrar domínio dos fundamentos do desenvolvimento Front-End.
